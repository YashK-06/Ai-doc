Synthetic Court Document Extraction Dataset
============================================

10 DOCX documents are provided in documents/.
Each DOCX has a matching ground-truth JSON file in labels/.

Fields:
- case_number
- applicant_name
- respondent_name
- lawyer_name
- court_name
- case_type
- filing_date
- address

These are synthetic examples created for ML/NLP experimentation and are not real legal records.
